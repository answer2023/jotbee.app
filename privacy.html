VoiceBee 隐私政策

生效日期：[待填] · 开发者：[待填 · ClearSky 工作室 / 主体名称]

VoiceBee 是一款 macOS 语音输入工具，把「数据尽量留在你自己手里」作为设计原则。本政策如实说明我们处理哪些数据、数据去了哪里、以及你能如何控制。

一、核心原则：你可以选择完全本地

VoiceBee 的语音识别和 AI 处理都支持完全本地运行。若你选择 WhisperKit 识别引擎 + 本地 Ollama 润色，你的语音和文字全程不离开这台 Mac。是否联网、用哪个引擎，由你在设置中决定。

二、语音音频的处理

VoiceBee 提供两种语音识别引擎，音频处理方式不同：

  • WhisperKit 引擎：语音在你的 Mac 上本地识别，音频不会上传。该引擎首次使用时需联网下载识别模型（约 626MB），下载后即可完全离线使用。
  • Apple 语音识别引擎（系统内置）：调用 macOS 的语音识别服务。根据 Apple 的机制，音频可能被发送到 Apple 的服务器进行识别，受 Apple 隐私政策 约束；是否本地由 macOS 系统决定。

VoiceBee 本身没有服务器，我们不接收、不存储、不转发你的任何音频。

三、文字的处理（AI 润色 / 翻译）

当你使用 AI 润色或翻译时，VoiceBee 会把「需要处理的文字 + 你设置的常用语言 + 你在词典中添加的专有名词」发送给你自己配置的 AI 服务：

  • 若使用云端服务（如 Claude、DeepSeek、Gemini、OpenAI 兼容接口），上述内容会发送到你选择的服务商，受其各自隐私政策约束；
  • 若使用本地 Ollama，文字仅在你的 Mac 上处理，不上传。

这些请求使用你自己的 API 密钥直接发往对应服务，VoiceBee 不做中转、不留副本。

四、数据存储（均在你的设备本地）

VoiceBee 不上传或备份你的任何个人数据。以下数据仅保存在你的 Mac 上：

  • API 密钥：存储在 macOS 钥匙串（Keychain），加密保护；
  • 历史记录：最近 50 条转写记录，保存在应用支持目录，可随时在设置中清空；
  • 自定义词典、使用统计：保存在本地。

五、权限说明

VoiceBee 需要以下 macOS 权限，仅用于其功能：

  • 麦克风：录制你的语音以进行识别；
  • 语音识别：将语音转为文字（仅 Apple 引擎需要）；
  • 辅助功能：读取你选中的文字（翻译功能）、将结果输入到当前应用。

六、我们不做的事

  • 不收集、不上传你的音频或文字到 VoiceBee 的服务器（我们没有服务器）；
  • 不含广告、不做用户追踪、不出售任何数据；
  • 不需要注册账号。

七、儿童隐私

VoiceBee 不面向 14 岁以下儿童，也不有意收集其个人信息。

八、政策变更

本政策如有更新，将在本页面公布并更新生效日期。
